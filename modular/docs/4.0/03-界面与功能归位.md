# 03 · 界面与功能归位

> 本文件回答两个问题：**每个功能在启动器里放哪**、**用户怎么用**。
> 不写实现细节（那在 05-IPC 与 06-核心流程里），只写界面契约。

## 0. 定位

启动器是**唯一入口**，不是控制台网页的壳。三条硬规则：

1. **一页一件事**。切页不跳窗、不新开标签。
2. **原生化**。7 页全部 WPF 原生控件，4.0 不引入 WebView2。3.x 的网页控制台保留为
   「设置 → 高级 → 打开网页控制台」的逃生入口，不在导航里露头。
3. **常驻提权**。启动器清单为 `requireAdministrator`，与微信同级；界面**不显示**提权状态，
   不弹「是否以管理员运行」，它就是管理员。

- **顶栏**：三个状态点 + `⟳重启` `⏻停止/启动` `⚙`。没有其他按钮。
- **左栏**：7 项，固定宽度 168px，可收起。
- **底栏**：一句话状态 + 数据目录 + 版本。**不放日志尾**——桥接每一行原文在「微信桥接」页，
  内核日志在「诊断」页。
- **托盘**：显示窗口 / 重启桥接 / 打开微信 / 退出。点 `×` 默认收进托盘（可在设置改）。

三个状态点的三色契约：绿=正常，黄=启动中/降级，红=掉线/失败。悬停出气泡，点一下跳对应页。

### 2.2 人设

用途：调她的性格、说话方式、群聊策略、主动程度、实验开关。

布局：左二级导航（7 组）+ 右表单，右栏滚动到锚点。

| 组 | 控件 |
| --- | --- |
| 身份 | 名字、别名、她怎么叫你、主人名单（wxid 多行，旁边给「最近说话的人」下拉直接抄） |
| 说话方式 | 私聊字数、群聊字数、气泡数、颜文字档位；每个滑块右侧实时渲染一句示例 |
| 群聊 | 必须 @、自由聊天几率、冷却秒数、每小时上限 |
| 情绪时间 | 心情时段曲线（只读）、活动时间段 |
| 主动 | 总开关 + 只找主人 / 允许进群 / 找非主人；时间窗、间隔、抖动、每日上限、安静期 |
| 预设 | 预设列表、导入、导出（导入前给 diff） |
| 实验开关 | `features` 注册表 11 项，每项显示默认值 + 「关掉回到什么行为」 |

保存规则：**每字段失焦即存**（PATCH 单字段），右下角浮出「已保存 14:22:03」。不整包提交。

危险项：管理员咒语、清空主人名单 → 红字说明 + 二次确认。

### 2.3 记忆

用途：看她还记得什么、备份、导出。

布局：顶部概览条 → 工具栏 → 左会话列表 + 右详情。

| 区域 | 内容 |
| --- | --- |
| 概览条 | 会话数 / 消息数 / 笔记数，点数字跳对应列表 |
| 会话列表 | 搜索 + 按最后活跃排序 + 未读小点 |
| 详情 | 消息流 + 她记的笔记（单条可删，删后 5 秒可撤销） |
| 备份恢复 | 立即备份 / 从备份恢复 / 打开备份目录。恢复前必须列出「将覆盖哪几个会话」 |
| 导出 | zip，可选含不含图片语音（默认不含） |
| 自动快照 | 开关 + 已存 N 份 + 占 X MB + 保留上限 + 清旧快照 |
| 危险区 | 清空某会话（输入会话名）/ 清空全部（输入「鲸鲸」） |

### 2.4 表情包

用途：管三个情绪分类的图片，发测试，看待发送队列。

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 总开关（默认关）+ 一句约束「只在她窗口在前台时发」 |
| 左分类 | 傲娇 / 炸毛 / 其他 + 各自张数（为 0 置灰） |
| 右网格 | 虚拟化图片网格，多选、Shift 连选 |
| 上传 | 拖文件进网格 或 点 `+` 选文件；重名自动改名不覆盖 |
| 单图操作 | 悬停：预览 / 删除 / 设为首选 / 在本机打开 |
| 发送测试 | 选分类 →【发一张】→ 就地返回：已发送 / 被前台门禁挡 / 桥接离线 |
| 队列 | 底部折叠：pending 列表 + 重试次数 + 【全部取消】 |

注意：提权后拖拽会被 UIPI 拦截，必须 `ChangeWindowMessageFilterEx(hwnd, WM_DROPFILES, MSGFLT_ALLOW)`
并放行 `WM_COPYGLOBALDATA (0x0049)`，否则拖拽静默失效。

- 桥接以 `python.exe -u` 启动，`PYTHONIOENCODING=utf-8`，stdout 与 stderr 都收。

- UI 每 200ms 批量取新增行，暂停时继续收、恢复时补齐，不丢行。
- 清屏只清视图，不清文件。

## 3. 跨页规则

1. **刷新节奏**：状态 2s，最近动态 5s，控制台 200ms 批量；其余页面进入时拉一次，改动后局部刷新。
2. **错误呈现**：页面内错误就地在动作旁边出结果行；全局错误走状态页横幅 + 顶栏红点。
3. **空态**：每个空列表都要有一句「为什么空 + 下一步做什么」，不放插图。
4. **危险动作**：一律 红按钮 + 输入确认词，不用「确定/取消」弹窗。
5. **不做的事**：不做新手引导浮层、不做卡通插画、不做深色/浅色双主题（只深色）。

## 4. 需要新增的后端接口与字段

| 项 | 说明 | 量级 |
| --- | --- | --- |
| `GET /api/recent?limit=10` | 最近消息流 `{ts, who, role, text, chat}`，现在没有 | ~30 行 |

| 桥接 stdout 分流 | 主管按来源分 `[K]`/`[B]`，供两页各自的日志视图 | 已有日志改造 |

## 5. 已定 / 待定

已定（2026-10-30）：

- **用量口径**：只统计「本次运行」，重启清零，**不落盘** `stats.json`。
- **最近动态**：**不给删单条**，只给复制；删聊天回微信里删，避免启动器与存储层对不上。
- **不表达提权**：界面不显示锁图标、不弹提权提示；启动器常态以管理员运行。

- **对话页**：4.0 不做，网页控制台降级为「设置 → 高级」里的逃生入口。
- **原生页面**：7 页全部 WPF 原生，不引入 WebView2。

实测：`测试连通` → `连通正常 · deepseek-chat · 598 ms`；`立即备份` → 快照从 2 变 3；七个页面切换无崩溃。

开发期要点：

- `RuntimeSupervisor` 接管 stdout/stderr（`PYTHONIOENCODING=utf-8`、`PYTHONUNBUFFERED=1`，**不设 TZ**——Windows 的 Python 会把 `Asia/Shanghai` 解析错，时间戳差 7 小时）。
- 任何未接住的异常写 `data/crash.log`；页面创建失败只坏一页，不带崩整个启动器。
- 提权清单还没翻：现在是 `asInvoker`，诊断页会如实显示「不是管理员」。翻转后每次启动弹一次 UAC，`ChangeWindowMessageFilterEx` 已就位，拖拽不会失效。
- `tools/dev_kill.py`：只杀鲸鲸自己的 node / python / 启动器，不碰别的进程。
