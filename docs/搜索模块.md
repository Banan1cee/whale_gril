# 搜索模块

聊天流程通过 `src/services/search.js` 的 `search()` 获取本轮证据。该服务不操作聊天存储，也不生成最终回复。

## 调用与结果

```js
const { search } = require('../services/search');
const value = await search({
  text, history, llm,
  config: config.websearch,
  now: new Date(),
  signal,
  trace: (stage, data) => logger.info(JSON.stringify({ stage, ...data })),
});
```

`history` 可以是字符串数组，也可以是延迟读取函数。关闭联网或跳过路由时不读取历史。

返回字段：

| 字段 | 含义 |
| --- | --- |
| `status` | `ok` 有可用证据；`skipped` 未执行；`empty` 查询完成但无有效证据；`failed` 查询失败或超时/取消 |
| `reason` | 结构化原因，例如 `disabled`、`no_results`、`stale_only`、`parse_error`、`deadline_exceeded` |
| `items` | 本轮可用资料，包含 `title/url/snippet/provider/fetchedAt/publishedAt`；天气另带 `weather` 结构 |
| `staleItems` | 已过滤的旧资料，只供诊断，不进入提示词 |
| `attempts` | 已执行阶段的来源、状态、耗时；失败时含 `code` 和 `error` |
| `elapsedMs` | 本轮总耗时 |
| `text` | 最后生成的提示词资料文本，空结果或失败时为空 |

`attempt.status` 是执行状态；HTTP 状态在 `attempt.error.status`，避免二者混用。

`fetchedAt` 是程序拿到数据的时间，不能当作网页发布时间。没有可靠发布时间时 `publishedAt` 为 `null`。缓存命中保留原获取时间。热榜只证明获取时的榜单，不证明事件发生在今天。

## 分层

- `src/services/search.js`：联网开关、路由、天气/热榜选择、总预算和跨来源回退。
- `src/core/search/policy.js`：本地路由兜底、平台约束、天气能力范围。
- `src/core/search/quality.js`：候选查询、相关性、型号匹配和时效过滤。
- `src/core/search/result.js`：统一结果协议和最终资料格式化。
- `src/adapters/searchRouter.js`：模型 JSON 路由；完整意图为 `kind/query/site/city/fresh/timeRange`，兼容旧格式。
- `src/adapters/search/`：传输、解析器、Bing、360 搜索、热榜、天气和公开数据缓存。
- `src/adapters/websearch.js`：结构化入口和旧函数兼容门面；定位服务仍可调用 `ipCity/geocodeCity`。

## 回退与时限

1. `semanticRoute` 未配置时只对疑似事实问题调用模型；`true` 每句调用，`false` 只走本地规则。
2. 明确的 `need:false` 跳过查询；路由失败或旧路由缺少分类字段时由本地策略兜底。
3. 常规天气优先 Open-Meteo，平台热榜优先对应接口；失败后进入普通搜索，保留问题日期和指定平台。
4. 普通搜索先 Bing，结果不足时尝试候选查询和 360 搜索（`www.so.com`，无需 Key）。指定平台既约束查询词，也校验返回链接的真实域名。360 结果仅采用真实落地链接，丢弃无法还原的跳转及站内链接；验证码或页面结构变化会如实报告失败。
5. 全过程共用 `websearch.timeoutMs`，默认 8 秒。语义路由最多 2 秒；天气/热榜最多使用路由后剩余预算的 60%，为普通搜索保留时间。
6. 所有网络请求支持 `AbortSignal`、绝对时限、重定向次数和响应体大小限制。候选检索失败不抹掉此前已有的有效证据。

天气接口只用于当前及今明两天常规天气。空气质量、台风路径、远期/历史或明确其他日期的请求走普通搜索。城市优先级：本句明确地点、配置城市、IP 推测；显式地点无法解析时保留原问题去搜索，不改查默认城市。

## 缓存与诊断

- 热榜缓存 60 秒；地理编码和 IP 城市缓存 6 小时。仅内存缓存，容量有限，不缓存失败或空结果。
- 相同公开数据请求合并；每个等待者的预算和取消独立，最后一位退出才取消共享请求。
- 搜索正文和语义路由不跨聊天缓存。
- `trace` 只记录来源、计数、状态、耗时与安全错误摘要。不要直接记录 `items`、问题正文或历史内容。
- 错误摘要通过 `describeError` 生成；外部异常消息可能包含 URL 或响应正文，因此先转换成结构化错误再记录。

## 验证

逐文件执行 `tests/search-*.test.js`、`tests/websearch-relevance.test.js`、`tests/weather.test.js` 和 `tests/c1c2c3.test.js`。网络回归用离线传输模拟，覆盖真实生产解析与取消路径；服务测试覆盖路由、状态、天气能力和提示词资料。提交前另跑仓库要求的分层、发布和隐私检查。
