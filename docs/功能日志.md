# 功能日志排查

在启动器「诊断」查看内核日志，「微信桥接」查看桥接日志；诊断时取消“仅错误”过滤。
本次新增信息使用 INFO 级别，不需要打开 DEBUG。

## 搜索 `[search]`

- `decision=skip`：看 `reason`。`disabled` 为联网关闭，`empty_input` 为无正文，`router_not_needed` 为没有命中联网条件。
- `router_failed_keyword_fallback`：模型路由失败，但规则判定仍需搜索。
- `stage=filter`：`parsed` 为解析到的候选数、`relevant` 为相关结果数、`rejected` 为被相关性过滤的数量。`parsed=0` 也可能是页面变化或反爬，不应认定网络上没有答案。
- `stage=result`：`stale` 为时效淘汰数、`selected` 为最终保留数，`sources` 是来源域名。为保护隐私不写检索原话、标题或摘要。
- `stage=failed`：错误类型、代码和 HTTP 状态。`deadline_exceeded` 为本轮预算已耗尽。
- “联网资料已注入提示词”：结果已交给模型，不能据此断言模型采用了每条资料。
- `[pipeline] result=skip`：消息在前置规则处被忽略，没有进入搜索/发送阶段，查看该行 `reason`。

## 语音 `[voice]`

`disabled` 关闭；`chat_type_disabled` 不允许当前私聊/群聊；`user_requested_text` 用户要求文字；
`explicit_voice_request` 明确要语音；`probability_hit/miss` 概率命中/未命中；
`error_or_command_reply` 为报错/命令回复。
`result=text_fallback` 表示语音准备失败，已改走文字；
`voice_may_have_sent` 表示可能已送出语音，为避免重复不再发送文字/表情。

## 表情包 `[sticker]`

`no_category_or_demand` 未获得可用分类/发送要求；`job_in_flight` 同会话已有任务；
`no_usable_image` 图库没有可用图；`reserved → sending → ack` 通过同一 `job` 串联。
回执 `reason` 区分超时、草稿、账号、目标会话、窗口、开关和媒体文件；
`unconfirmed` 表示未确认，不是成功，也不会自动重发。
总开关关闭遵循既有约定，不输出表情包日志。
