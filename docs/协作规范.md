# 协作规范

本文件管两件事：**提交信息怎么写**（所有人、所有提交都按这个来），以及提交前的自检。
内容型约定（测试、目录边界）见 `CONTRIBUTING.md`。

## 一、提交信息的结构

```
<范围>: <一句话说清这次做了什么>

一、新增
1. 功能名
   - 具体改动
   - 具体改动
2. 功能名
   - 具体改动

二、改进
1. 已有功能名：改成了什么样
   - 以前是 A，现在是 B，为什么

三、修复
1. 现象：原来会怎样
   - 根因
   - 现在的结果

四、其他
1. 打包 / 目录 / 文档 / 依赖 / 清理
```

硬性要求：

1. **标题一行**，`范围` 可选（`launcher` / `bridge` / `memory` / `sticker` / `installer` / `docs`…），一句话说清做了什么，不写「更新」「修改」「若干优化」这种空话。
2. 正文四段**顺序固定**：新增 → 改进 → 修复 → 其他。**某段没有内容就整段删掉**，不要留空标题。
3. 每段内的条目**编号**，细则用 `-` 缩进；**一条改动一行**，一条只讲一件事。
4. 不要写散文式的大段说明。需要讲「为什么」时，跟在对应那一条下面一行即可。
5. 同一个改动只归一类，不要既算「改进」又算「修复」；确实两边都沾，按下面的口诀选一类，并在那一行把另一半说清楚。

## 二、四个分类怎么分

| 分类 | 判定标准 | 例子 |
| --- | --- | --- |
| **新增** | 以前没有、现在有了：新功能、新模块、新文件、新接口、新页面 | 启动器（WPF 界面）、动作账本模块、`POST /api/stickers/category` 接口 |
| **改进** | 功能本来就有，但**运作方式或呈现形式变了**：行为、判定、显示、默认值、文案、性能 | 模型能看见自己做过的事、表情包可以自定义分类、设置从网页版搬进启动器、提示词措辞调整 |
| **修复** | 功能**本来就该能用，却跑不出结果或结果错**：崩溃、报错、乱码、发不出去、算错、显示错 | UIA 热激活失败、发送中文乱码、启动器打开桥接页崩溃、时间戳差 7 小时 |
| **其他** | 不属于上面三类：打包、安装包、运行环境、目录结构、依赖、文档、清理缓存 | 运行环境移进安装包、安装包瘦身、删除根目录旧结构、安装包排除表调整 |

判断口诀（从上往下，第一个中的就是它）：

1. **以前压根没这个东西** → 新增。
2. **有这东西，但它的行为或长相交了** → 改进。
3. **有这东西，却根本用不了 / 结果不对** → 修复。
4. **跟用户能感知的功能无关**（打包、环境、目录、文档、清理）→ 其他。

几个容易分错的：

- **加了一个配置项、但它改了已有行为** → 改进（配置项本身不算新功能）。
- **一个 bug 修完后功能表现跟以前明显不同** → 修复，在那一行写清「以前 → 现在」。
- **功能没变，只是换了个界面承载** → 改进（呈现形式变了），不是新增。
- **安装包里多了或少了一个文件** → 其他，不是新增/修复。

## 三、完整示例

```
sticker: 自定义分类 + 动作账本

一、新增
1. 动作账本（src/core/events.js）
   - 记录表情包、文字发送、读链接、联网四类外部动作
   - 存在会话 events 字段里，不进聊天记录，每轮回读最近 12 条
2. 表情包分类接口 POST /api/stickers/category
   - 支持 add / rename / remove，分类表存 data/sticker-categories.json

二、改进
1. 表情包可以自己加分类
   - 以前只有傲娇/炸毛/其他三类，现在一分类一文件夹，自己加的自己管
   - 删除分类只移出列表，文件夹和图片保留
2. 模型能知道自己做过什么
   - 以前发完表情包，下一轮模型完全不知道，只能编或装傻
   - 现在提示词里注入【最近做过的事】，按回执说话

三、修复
1. 微信 4.2 发出去的中文是乱码
   - 根因：4.2 的 WM_CHAR 收 UTF-16 码元，代码还在按 4.1 的 GBK 字节发
   - 现在按 Weixin.dll 版本自动选编码，数据库回读正常

四、其他
1. 安装包
   - 运行环境移进安装包，排除表补齐，体积 142.9 MB
   - 不再打包 web/、tests/、data/
```

## 四、提交前自检

- [ ] `node --test "tests/*.test.js"` 全绿（目前 637 条；**不要加 `--test-isolation=none`**：
      上游带过来的测试会用 `t.mock.method` 替换 `https.get` / `websearch` 函数，
      单进程并发跑会互相污染，默认「一个文件一个进程」才是对的）
- [ ] 涉及桥接/UIA 的改动，Python 用例也跑过
- [ ] `git status` 里没有 `data/`、`wechatauto_db/`、日志、缓存、安装包产物
- [ ] 提交信息按上面四段写完了，没有漏归类
- [ ] **只在被明确要求时提交**；提交前先看一遍 `git diff --stat`
