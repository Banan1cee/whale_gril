# 语音发送（实验性）

语音发送页第一行是「启用语音发送（实验性）」总开关，默认关闭。关闭时其他配置全部隐藏；不抽取语音概率、不响应“发语音”的特殊指令、不创建语音任务、不调用语音模型、不操作微信录音。文字聊天仍按原规则运行。

总开关切换后立即保存，无需另点保存。关闭时取消界面列表请求，并给已排队/执行中的语音任务留下取消标记；工作进程取消合成、停止播放并尝试取消录音。重新打开不会复活已取消任务。已真正发送的消息无法靠关闭开关撤回。

打开开关后才能看到概率、群聊/私聊、BreezeBlue 模型和音色、语气、Key、虚拟声卡等设置。Key 使用 Windows 当前用户加密保存在本机，源码和 GitHub 不包含 Key。

## 自定义录音快捷键

默认 **Ctrl+Alt**。在可编辑快捷键框里选择或输入，例如：

- Ctrl+Alt
- Alt+=
- Ctrl+Shift+F11
- F11

支持 Ctrl/Control、Alt、Shift、字母、数字、F1～F24 和 = 号；修饰键可单独组成快捷键。两边设置必须一致：微信里“发语音”的按住快捷键要与这里相同。程序会先核对微信显示的快捷键，再自动按住组合键录音，完成后反向松开；用户无需手动按键。

## 自动回复行为

原聊天模型先生成正常回复，语音模型只把同一段正文合成音频。随机概率可设为 0～100%，每条机器人回复只抽一次。0% 时仅响应明确的语音要求；总开关关闭时任何情况都不发语音。

运行包已附 VB-CABLE 官方安装包，可在开关打开后从本页启动安装；驱动须安装到 Windows，可能要求重启。程序播放端选 CABLE Input，微信麦克风选 CABLE Output。VB-CABLE 来源 https://vb-audio.com/Cable/ ，为 VB-Audio Donationware，欢迎向官方捐赠/购买许可。

设置完成后保存，重启内核及桥接。后续按概率或对方请求自动发送，不需要一直打开本页。合成或准备失败可回退原文字；一旦可能已录音发送，不自动补发，避免重复。

## 两个测试按钮

打开实验开关后可以使用：

- 「测试 API Key 连接」：使用输入框里的 Key；留空则使用本机已保存的 Key。调用模型列表接口检查连接与鉴权，不合成语音。15 秒未完成显示「API Key 不可用：连接超时」；鉴权或网络失败显示不可用，成功显示可用。结果直接显示在按钮下方。
- 「发送测试语音到文件传输助手」：先保存当前配置，使用所选模型、音色、虚拟声卡和微信录音快捷键，固定发送「哈喽哈喽，可以听见我说话么」。需要启动新版桥接；该测试不受随机概率或群聊/私聊范围限制，始终受实验总开关控制。点击后自动完成合成、切换到文件传输助手、录音和发送；测试期间按钮不能重复点击。此操作会调用语音合成接口。

发送测试沿用桥接的账号与会话校验以及发送互斥锁。关闭开关或离开页面会取消正在进行的测试。程序只确认录音和发送操作是否完成，送达及声音效果需要到文件传输助手试听；不确定结果不会自动重发，也不会补发文字。旧请求在桥接重启后不会重复执行。

构建工具与开发缓存保存在运行包外的 Documents/whale-girl-build-cache。仅本地更新，GitHub 上传时只提交源码、测试、项目依赖和必要说明，不提交运行时、exe、data、密钥、驱动安装包或开发缓存。
