## 一、语音

语音是这两天唯一一个"新增功能"，其余全是在修它周围的东西。

| 提交 | 内容 |
| --- | --- |
| `75cc3e1` / PR #26 | 语音发送实验功能 + 测试工程 |
| `1687666` / PR #27 | 完整语音教程，预选中英双语模型与机灵版音色 |
| `6e38ad5` | worker 不走本地代理；合成超时 20 → 85 秒 |
| `50ab47c` | 合成超时从写死的 125 秒改成可配（默认 20 秒，后修正为 85） |

两个坑值得记下来：

1. **代理**。语音 worker 用 `HttpClient`，.NET 会自己读 `HTTP_PROXY`，于是被 Clash 拦住，一条 41 秒的合成要等 362 秒。改成 `UseProxy=false`。
2. **超时不是卡死**。BreezeBlue 本身就要 40 秒出一条语音。我把超时压到 20 秒那一版是错的，回退到 85 秒。

> 现状：能发，但一条语音消息就是要等 40 秒左右，这是接口速度，不是程序问题。

## 十一、还没验证 / 风险

1. **语音仍是实验性**：只有测试工程覆盖，真机通话没跑过；且一条语音本来就要等 40 秒。
2. **编码实测只跑过 4.1.15.56**：WM_CHAR 探针能自动区分，但 4.2 真机还没各发一条中文验证。
3. **自定义看图接口**只做了 HTTP 端到端回归，没接陌生中转站实测。
4. **安装包仍未签名**：167 MB 只是能装能跑，SmartScreen 还是会提示未知发布者。
5. **不支持 x86**：运行时是 win-x64，32 位系统装上也跑不起来。
