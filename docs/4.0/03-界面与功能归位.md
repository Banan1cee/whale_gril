# 03 · 界面与功能归位

> 本文件回答两个问题：**每个功能在启动器里放哪**、**用户怎么用**。
> 不写实现细节（那在 05-IPC 与 06-核心流程里），只写界面契约。

## 0. 定位

启动器是**唯一入口**，不是控制台网页的壳。三条硬规则：

1. **一页一件事**。切页不跳窗、不新开标签。
2. **原生化**。7 页全部 WPF 原生控件，4.0 不引入 WebView2。3.x 的网页控制台
   （`web/debug.html`）目前没有在启动器里提供入口，只能直接用浏览器打开，不在导航里露头。
3. **常驻提权**（目标态）：启动器清单为 `requireAdministrator`，与微信同级；界面**不显示**提权状态，
   不弹「是否以管理员运行」，它就是管理员。**当前清单仍是 `asInvoker`**，诊断页会如实显示
   「不是管理员」，详见第 6 节。

### 2.2 人设

用途：调她是谁、怎么说话、情绪与主动性、实验开关。

布局：单列滚动卡片（不做左侧二级导航），底部固定一行保存状态 +【全部保存】。

| 组 | 控件 |
| --- | --- |
| 身份 | 名字、她怎么叫你、年龄、职业、外观、性格、背景、自定义提示词 |
| 主人身份 | 别名 / 外号、主人名单（昵称）、主人名单（wxid）、主人骂她时允许还嘴 |
| 说话方式 | 私聊字数上限、群聊字数上限（右侧实时预览一句多少字）、历史轮数、群聊历史轮数、**颜文字用量（0–100% 拖动条）**、最多分几条消息 |
| 情绪与主动性 | 有情绪、会主动找话题、有自己的看法、会看链接内容 |
| 人设预设 | 预设下拉 +【导入这版】（导入会覆盖身份与说话方式对应字段） |
| 实验开关 | `features` 注册表 13 项，本页只显示 6 项；已有专页的 7 项（双开守卫、引用回复、表情包、主动搭话 4 项）不在这里重复 |

保存规则：字段失焦后 450 ms 防抖，**整包 POST `/api/persona`**，再补一次 config patch
（主人名单、`chat.emojiChance` 等 persona 接口不收的键）；右下角显示「已保存 14:22:03」。

颜文字拖动条：位置 = 百分比概率，保存在 `chat.emojiChance`（0.00–1.00）。
拖到 0% 会同时把档位写成「关」做硬关；拖到 >0% 时档位恢复为可用值。
显示「约每 N 条带一次」，不会出现拖到 0 却还在发的矛盾。

群聊规则（必须 @、自由插话、插话概率、冷却、每分钟上限等）统一在「设置 → 群聊」，
本页不再重复。主动搭话的时间窗 / 间隔 / 白名单在「主动与提醒」页。

### 2.3 表情包

用途：管三个情绪分类的图片，发测试，看待发送队列。

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 总开关（默认关）+ 一句约束「只在她窗口在前台时发」 |
| 目录与概率 | 表情包目录（可编辑，相对路径）、三类图片概率（傲娇 / 炸毛 / 其他，0–1）。这两个原来在「设置 → 表情包」，已归位到本页 |
| 左分类 | 傲娇 / 炸毛 / 其他 + 各自张数（为 0 置灰） |
| 右网格 | 虚拟化图片网格，多选、Shift 连选 |
| 上传 | 拖文件进网格 或 点 `+` 选文件；重名自动改名不覆盖 |
| 单图操作 | 悬停：预览 / 删除 / 设为首选 / 在本机打开 |
| 发送测试 | 选分类 →【发一张】→ 就地返回：已发送 / 被前台门禁挡 / 桥接离线 |
| 队列 | 底部折叠：pending 列表 + 重试次数 + 【全部取消】 |

注意：提权后拖拽会被 UIPI 拦截，必须 `ChangeWindowMessageFilterEx(hwnd, WM_DROPFILES, MSGFLT_ALLOW)`
并放行 `WM_COPYGLOBALDATA (0x0049)`，否则拖拽静默失效。

### 2.4 主动与提醒

用途：管「她什么时候主动找你」和「定时提醒」。两套配置放同一页，因为它们共用一套频率心智。

布局：上方两张配置卡（提醒规则 / 主动搭话），下方是提醒列表。

| 区域 | 内容 |
| --- | --- |
| 提醒规则 | 开关、每天最多几次（0 = 不限）、刚聊过先跳过（分钟）。写在 `reminder.*`，与主动搭话配置独立 |
| 主动搭话 | 开关、平均间隔、间隔浮动、每日上限、刚聊过先跳过、允许时间段（跨零点也认）、只找主人 / 允许进群 / 找别人、白名单、黑名单 |
| 白名单 / 黑名单 | 联系人选择器：chips 展示 + 弹窗多选 + 「全部静音（*）」。**选完立即保存**，和「保存主动搭话」按钮互不干扰 |
| 提醒列表 | 每条显示时间、目标（昵称 / wxid）、内容、状态（待发 / 重试中 / 已发 / 失败 / 已过期 / 已取消）、失败原因，右侧【删除】 |

白名单 / 黑名单必须是选择器而不是多行文本框：两个键里存的是 wxid，手抄必错。
选择器直接从 `/api/wechat/contacts` 拉联系人；接口没就绪时退化成显示原始 wxid 并说明原因。

「主动搭话」的四个开关（`care.enabled` / `care.onlyMaster` / `care.allowGroups` / `care.allowOthers`）
在 `features` 注册表里也有同名项，**本页是唯一界面入口**——人设页的实验开关已把这四项隐藏，
不要再加第二份。

控制台技术契约：

- 桥接以 `python.exe -u` 启动，`PYTHONIOENCODING=utf-8`，stdout 与 stderr 都收。
- 主管把每行加来源前缀写入内存环形缓冲（3000 行）与 `data/bridge.log`；文件按 5MB × 2 轮转。
- UI 每 200ms 批量取新增行，暂停时继续收、恢复时补齐，不丢行。
- 清屏只清视图，不清文件。

归位约定：

- **表情包目录与三类概率**在「表情包」页，设置里不再有「表情包」分类。
- **微信账号、打字编码、码元间隔、托盘自动开窗、发送后回读、跳过 GBK** 在「微信桥接」页的
  「账号与发送」区，设置里不再有「微信 · 账号与发送」分类。
- **双开守卫、引用回复、发送方式**也在「微信桥接」页，设置页不重复。
- **关于**（版本）在界面左下角（左栏导航下方），设置里不再有「关于」分类；
  配置文件 / 数据目录 / 表情包目录的入口在「诊断 → 路径与占用」。
- **她怎么叫你**在人设 · 身份，设置页不再重复。
- **字数上限、颜文字用量、最多分几条**在人设 · 说话方式；设置页没有「聊天与气泡」这一类。
- **功能开关**只保留人设页那一份（由 `/api/features` 动态生成）；设置页没有手写的功能开关卡。
- `wechat.backgroundSend` 是没有消费方的死键，界面不提供。

## 3. 跨页规则

1. **刷新节奏**：状态 2s，最近动态 5s，控制台 200ms 批量；其余页面进入时拉一次，改动后局部刷新。
2. **错误呈现**：页面内错误就地在动作旁边出结果行；全局错误走状态页横幅 + 顶栏红点。
3. **空态**：每个空列表都要有一句「为什么空 + 下一步做什么」，不放插图。
4. **危险动作**：一律 红按钮 + 输入确认词，不用「确定/取消」弹窗。
5. **不做的事**：不做新手引导浮层、不做卡通插画。**做**深色 / 浅色双主题 + 背景图（只影响启动器本身，不写进 config.json）。
