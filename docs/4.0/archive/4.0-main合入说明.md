## 合入的修复

- 桥接退出后的受控恢复、账号/连接配置变化时重连、手动停止取消恢复、连续故障停止重试。
- 服务就绪同时核验服务标识与进程 PID；启动器单实例；明确区分进程运行与服务就绪。
- 表情包重复点击去重、完整图片 ID、结果刷新与中文状态、失败后停止后续发送、轻量安全核验。
- 图片识别请求体上限、长截图 JPEG MIME、自发图片提前过滤、错误响应和 token 失配提示。
- 保留 main 的连发合并，移植时不再在出队后重复判断过期。
- 语音凭据只发往匹配服务商或使用专用 Key；原生表单测试使用当前输入，失败时保留密钥输入。
- 未授权聊天真正停止处理；非法 JSON/URL 编码和中断上传处理；账号刷新失败不伪装成功。
- 提醒任务状态、重复回执、每日额度、失败落盘回滚和有界重试。
- v2 备份输入校验与跨服务商脱敏恢复的凭据隔离；不改变 v2 的核心存储实现。
- CLI 记忆工具修正依赖，服务在线时拒绝直接覆盖磁盘数据。
- 停止/部署仅操作目标目录，停止前保存；恢复出厂在停止或备份失败时中止。
- 本机运维端点 `/api/runtime/prepare-stop` 要求本机令牌，只返回成功/失败；它不返回任何记忆正文，也不是记忆导出/恢复接口。写盘仍未完成时拒绝停止准备。
- 更新前递归检查代码；发布和安装选取重新编译的成品，启动器内置 .NET。
