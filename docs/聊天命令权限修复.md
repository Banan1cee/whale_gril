# 2026-11-03 聊天命令权限修复

普通群成员可以通过 `/reset` 删除整个群聊的记忆，原因是普通命令分支漏做权限校验。已在临时存储中复现，攻击测试不接触真实微信、Key 或记忆。

- `/reset`、`/clear`、全角符号、大小写变体及中文重置命令统一要求发送者 ID 与配置的主人 ID 匹配；清空所有记忆同样仅限主人。
- 同名昵称只保留关系称呼的兼容用途，不能获得管理员权限；外部传入的 `isMaster` 标记不作为凭据。
- 群聊 `/mute`、`/unmute` 仅限主人。普通成员仍可记住或忘记自己的信息，不能删除他人的笔记。
- 普通用户 `/status` 不返回具体模型和记忆数量。
- 管理身份每次按当前配置复核，旧的临时授权记录不能在撤权后继续生效；`allowAll` 必须是布尔值 true 才能开启。即使开启 allowAll，非主人也不能清空记忆。
- 浏览器写请求按实际协议、主机和端口验证同源，其他本机端口不能借 localhost 绕过检查。

主人需要在设置中绑定实际发送者 ID，微信使用内部 wxid，昵称或自设微信号不作为管理权限的兜底。未绑定时清空命令会拒绝执行；本机启动器管理接口保留原有用途。

本次不改变记忆格式、检索或压缩算法。被旧版删除的内容不会因修复自动恢复；恢复备份前应先保留现有记忆，避免覆盖新聊天。

本次覆盖聊天命令授权、真实 HTTP 桥接身份、跨站请求及权限撤销。自然语言“退下/滚”等社交静默行为按原设计保留；本次不是对所有模型输出和提示词攻击的完整安全保证。
