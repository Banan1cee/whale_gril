## 2. 期限与范围

### 2.1 窗口五个阶段（D0 + 四天）

| 阶段 | 做什么 | 验收 | 主要风险 |
| --- | --- | --- | --- |
| **D0 前置**（1–2h） | 装 .NET 10 SDK（`dotnet-install.ps1`，免管理员，装到 `~/.dotnet`）+ Inno Setup 7（已装） | `dotnet --list-sdks` 有 10.x；`ISCC.exe` 可执行 | **本机两者都没有装**，不装 D3 无从谈起 |
| **D1 运行环境** | 新脚本 `scripts/build-runtime.ps1`：node 24 + CPython 3.12 embeddable + wheelhouse（wechatauto-replica==1.2.8.1 / psutil / pywin32）+ pywin32 postinstall + `runtime/manifest.json` | `runtime\python\python.exe -c "import wechatauto,psutil,win32com"`；`runtime\node.exe server.js --doctor` | pip 源与 python.org 下载；pywin32 postinstall 的注册表写入 |
| **D2 安装包** | 新文件 `installer/whale.iss`，扩 `scripts/build-release.ps1` 加 `-Installer` | 装到 `%LOCALAPPDATA%\Programs\鲸鲸`；桌面/开始菜单快捷方式；VCRedist 静默；卸载保留 `data` | Inno 脚本调试；杀软 |
| **D3 启动器** | 新目录 `launcher/`（WPF .NET 10 + WebView2）：单实例、托盘、起停两个子进程、状态灯 | 双击进托盘 → WebView 打开页面 → 能聊；托盘能停能起；关窗不退进程 | **最紧的一天**，见降级预案 |
| **D4 收口** | 干净机全流程（装 → 配 → 聊 → 发表情包 → 卸载）+ 已知问题说明 + 发布页文案 | `鲸鲸-4.0-alpha-setup.exe` 能发给别人 | 真机验证压不下去 |

**进度（2026-10-29）**：

- **D0 完成**：.NET SDK **10.0.403**（`C:\Program Files\dotnet`）、Inno Setup 7（`C:\Program Files\Inno Setup 7\ISCC.exe`）
- **D1 完成**：`runtime\` 已产出 —— node.exe v24.18.1、CPython 3.12.10（26 个包）、`manifest.json`；
  `node server.js --doctor` 与 `import wechatauto, psutil, win32com, uiautomation` 均通过
**降级预案（按顺序砍，先砍后两项）：**

1. D3 的 WPF 来不及 → 交付「安装包 + 现有 `启动鲸鱼娘.bat`」，WPF 挪 beta。仍满足「能装能跑」。
2. 启动器先不做 WebView2 内嵌 → 直接调用系统浏览器（alpha 临时允许，beta 收回）。
3. Inno Setup 卡住 → 用 7-Zip SFX 自解压 + 安装脚本兜底。

**alpha 的数据位置（简化版）**：整包装在 `%LOCALAPPDATA%\Programs\鲸鲸`（per-user，可写，不弹 UAC），`data\` 在安装目录内——**代码零改动**。Roaming / Local 拆分和 `WHALE_DATA_HOME` 迁移放 beta（JS 5 处 + Python 15 处硬编码，要一天）。

### 2.2 四天不做

- 原生配置页（用 WebView2 承载现有页面）
- 分块自动保存重构
- 一键诊断包 / 自动更新 / 代码签名
- 桥接换 SPI 物化（要真机长测，放 beta）
- 完整迁移向导 → alpha 只做「复制旧 data 目录」
- 把 `data/` 从安装目录移到 AppData（见 2.1）

### 2.3 完整 4.0 验收（beta 收口）

1. 干净 Windows 双击一个 exe，10 分钟内能聊天；失败时自己说清「缺什么、点哪里」。
2. 3.63 升上来：记忆、人设、表情包库、配置全在。
3. 发不出去时：看得到走哪条通道、为什么降级、最近一次失败。
4. 改任何设置：不重启生效，或明确提示需重启。
5. 出问题：一键导出诊断包。

## 3. 形态

### 3.1 分层

```
安装器 installer.exe        打包 VC++ / Python / Node / 启动器
  └─ 启动器  WPF · .NET 10  唯一入口：配置 + 状态 + 托盘
       │  本机 HTTP（回环 + 随机端口 + 一次性 token，对外不暴露）
       ├─ 内核    Node      人设 / 记忆 / LLM / 网关 / 表情包库
       └─ 桥接    Python    UIA 读 / PostMessage 写

runtime/  python · node · vcrt
data/     见 3.2
```

12 个 `.bat` 收敛成 1 个快捷方式。

### 3.2 数据目录

| 位置 | 放什么 |
| --- | --- |
| `%APPDATA%\鲸鲸\` | config.json、记忆、人设、备份快照 |
| `%LOCALAPPDATA%\鲸鲸\` | 表情包库、媒体缓存、日志、运行时状态 |
| 安装目录 | 只有程序本体和 runtime（只读） |
| 便携模式 | 安装目录可写时，数据全落安装目录 |

内核新增 `dataRoot` 解析，所有路径从它派生，任何模块不得自己拼 `data/`。

### 3.3 配置八块（启动器）

| 分区 | 内容 | 保存 |
| --- | --- | --- |
| 模型 | 主模型 / 端点 / Ollama / 看图 / 语音 Key | 失焦即存 + 测试连接 |
| 人设 | 预设、称呼、语气、导入导出 | 800ms 防抖 |
| 记忆 | 快照、备份、恢复 | 按钮式 |
| 表情包 | 五类、概率、上传、试发 | 拖拽即存 |
| 微信 | 账号、DB 路径、通道开关 | 选择即存 + 自动探测 |
| 网关 | 平台开关、令牌、端口 | 800ms 防抖 |
| 系统 | 自启、托盘、日志级别、更新 | 开关即存 |
| 诊断 | 诊断包、日志、版本 | 只读 |

规则：每块右上角「已保存 22:41」哑光提示，不弹窗；未保存的分区左导航打点；危险字段走「保存并验证」。

## 4. 技术

### 4.1 选型

| 层 | 选定 |
| --- | --- |
| 启动器运行时 | .NET 10 LTS 自包含（.NET 8 支持到 2026-11-10） |
| 启动器 UI | WPF + WPF-UI + WebView2 |
| 内核 | Node，零 npm 依赖 |
| 桥接 | Python 3.12 embeddable |
| 安装器 | Inno Setup 7（已安装，`C:\Program Files\Inno Setup 7\ISCC.exe`） |
| 托盘 | H.NotifyIcon.Wpf |
| 更新 | Velopack（beta 再接） |
| 单实例 / 自启 | Mutex / 注册表 Run 键 |

**WebView2 Runtime 不是系统必装件**：安装器检测 + 微软 bootstrapper（2MB，联网拉约 100MB）。离线内置固定版（+130MB）留到正式版。

### 4.2 体积

| 组件 | 体积 | 来源 |
| --- | --- | --- |
| 启动器（WPF 自包含） | 70–90MB | 预估 |
| Node | 88MB | 实测：node.exe v24.18.1 |
| Python 3.12 embed + 依赖 | **383MB** | 实测（26 个包） |
| VC++ redist | 25MB | 预估 |

实测明细（`runtime/` 共 596MB，其中 wheelhouse 117MB 只是构建缓存，**不进包**）：

- opencv-python 与 numpy 是最大的两块（wechatauto 依赖 opencv，绕不开）
- imageio-ffmpeg 自带 ffmpeg 二进制，所以「ffmpeg 不打」这条实际上被依赖带进来了
- winsdk / cryptography / pywin32 / Pillow 合计约 60MB

**修正后的预期**：安装后约 550–600MB，安装包约 200–260MB（LZMA 压缩比待 D2 实测）。

### 4.3 Python 随包：构建期做完，用户端零网络

1. 钉死 CPython 3.12.x embeddable-amd64。
2. 改 `._pth`：加 `Lib\site-packages` 和 `import site`。
3. `pip download --only-binary=:all: --platform win_amd64 --python-version 3.12` 拉全部 wheel。
4. `pip install --no-index --find-links wheelhouse --target runtime\python\Lib\site-packages`。
5. 用私有 python 跑 `pywin32_postinstall.py -install`。
6. 自检 `import wechatauto, psutil, win32com` 通过 → 目录 sha256 写进 manifest。

安装器只做「校验 → 解压 → 自检」，不做推理。

## 5. 桥接

### 5.1 三条通道

| 通道 | 手段 | 抢前台 |
| --- | --- | --- |
| 读 | `SPI_SETSCREENREADER=TRUE` 物化 + `FindAll(Descendants)` | 否 |
| 点 | `PostMessage` MOUSEMOVE → LBUTTONDOWN/UP（客户区坐标） | 否 |
| 写 | 伪造 `WM_SETFOCUS` + GBK 逐字节 `WM_CHAR` | 否 |

实测 224 次采样 0 次被抢。绝不发 `WM_ACTIVATE`。

### 5.2 表情包：外部图库 + 粘贴，接受抢前台

抢占不可避免，目标是把次数和时长压到最小：

| 手段 | 做法 |
| --- | --- |
| 合并抢占 | 一批内容（文字 + 表情）合成一次前台会话，N → 1 |
| 挑空闲时刻 | `GetLastInputInfo` 最近 2 秒无输入才抢，正在打字就排队 |
| 抢完立即还原 | 记录前景 hwnd + 最小化/几何状态，发完立刻还，单次 300–500ms |
| 空闲批量发 | 用户不在机器前时发（锁屏可用性待实测） |

还原失败要兜底：宁可让微信留在前台并给托盘提示，也不能让用户没有可用窗口。

### 5.3 硬约束

- **微信最小化 = 全套失效**：UIA 只剩 2 节点、`PrintWindow` 只有 3 种颜色。启动器检测 `IsIconic`，暂停通道、托盘变黄、提示一次「请别最小化（被挡住没关系）」，**绝不偷偷恢复**。
- **权限必须与微信同级**：微信是管理员时普通权限投递静默失败（`GetLastError=5`）。
- **GBK 限制**：emoji、部分生僻字、日文假名发不出去。
- **别看 `SPI_GETSCREENREADER` 读回值**，判据是数节点。

### 5.4 上游库 wechatauto-replica

Apache-2.0，锁 `==1.2.8.1`，wheel 进 wheelhouse。两条路线：读走本机 SQLCipher 解密（不抢前台），发/交互走坐标 + OCR + 剪贴板粘贴（抢前台）。

**借它的控件层，换它的发送层**：`mmui::*` 控件树、DB 表结构、消息类型码（1 文本 / 3 图片 / 34 语音 / 43 视频 / 47 表情 / 49 文件）、`real_sender_id` 按分片解析——这些自己重造是几个月。

它物化 UIA 靠热激活 `Weixin.dll` 里的 gate 字节（版本敏感、要维护版本表），我们换成 `SPI_SETSCREENREADER`（系统参数、与版本无关）。

缓存接管：`%TEMP%\wechatauto_db\`、`~/.wechatauto\layout-<machine>.json` 一律指到 LocalAppData。改解密逻辑必须 bump `STAMP_VERSION`，否则「数据库磁盘映像损坏」死循环。

### 5.5 桥接改造（beta）

1. 物化换成 SPI，其余不动。
2. 文字发送换成 PostMessage；表情包保持粘贴。
3. 锁版本 + 接管缓存。

桥接 4.0 内不改 C#，4.1 再评估。

## 6. 签名

**alpha 不签名**，用户多点两步（更多信息 → 仍要运行）可以接受。

Azure Artifact Signing 走不通：官方地理限制把中国大陆排除在外，个人只限美加。

后果分档：普通 Win10/11 可手动放行；**Win11 全新安装 + 智能应用控制开着可能直接拦**（关掉后无法再开）；企业 AppLocker 硬挡；国内杀软看行为，签名降不了多少。

alpha 三件替代动作：发布页给 SHA256 + 三步放行图文；过 VirusTotal 并向火绒/360 提交误报申诉；Inno Setup 7 打正规安装包。

长期：开源走 **SignPath Foundation**（免费，需 OSI 许可 + 公开仓库 + 可复现构建 + 每次发布人工审批）；闭源买 **OV**（千元级/年，审核 1–2 周）。
