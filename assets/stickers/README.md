# 鲸鲸预设表情包

- 维护者提供的原图：傲娇、开心、炸毛各 9 张 PNG，共 27 张；未转码或压缩。
- 图片名包含内容哈希，`manifest.json` 记录完整 SHA-256，导入和发布时都会校验。
- 此处是随包资源，不是用户图库。首次开启表情包功能后，后台将图片复制到当前 `sticker.dir`（默认 `data/stickers`）。同名用户文件不会被覆盖。
- 图库中的 `.whale-presets-v1.json` 记录已初始化；后续启动不再补图，因此用户删除的预设不会复活。自定义图片和分类仍在启动器「表情包」页管理。
- 总开关默认关闭，关闭时不导入，也不会因为安装了预设自动发送消息；离线浏览维持只读，需启动内核并开启功能才初始化。
